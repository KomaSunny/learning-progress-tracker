## 1. 選定方針

- 何を最優先に選ぶか（例：学習コスト・運用コスト・パフォーマンス・チーム習熟度）

## 3. 比較サマリ

- 採用 / 不採用となった主な技術と、その判断根拠を簡潔に残す。

## 4. リスクと対応

- 採用技術ごとの懸念点と、緩和策。
