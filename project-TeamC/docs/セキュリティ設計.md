# セキュリティ設計

## 1. 脅威モデル

- 想定する脅威アクター
- 守るべき資産（個人情報、認証情報、業務データ など）
- 想定攻撃シナリオ（STRIDE 等の観点で整理）

## 2. 認証・認可

- 認証方式（パスワード + MFA、OAuth、SSO 等）
- パスワードポリシー / ハッシュアルゴリズム（bcrypt / argon2 等）
- セッション / トークン管理（JWT の有効期限、リフレッシュ方式）
- 認可（RBAC / ABAC、最小権限の原則）

## 3. 通信のセキュリティ

- TLS バージョン・暗号スイート
- HSTS / セキュアクッキー / SameSite
- CORS ポリシー

## 4. 入力・出力対策（OWASP Top 10）

- SQL インジェクション対策（プリペアドステートメント）
- XSS（出力エスケープ・CSP）
- CSRF（トークン / SameSite クッキー）
- アップロードファイル検証
- レート制限 / Bot 対策

## 5. 機密情報の取り扱い

- シークレット管理（環境変数、シークレットマネージャー）
- ログ・エラーメッセージへの混入防止
- 個人情報のマスキング・暗号化

## 6. インフラ・運用面のセキュリティ

- IAM / 最小権限
- ネットワーク（VPC / セキュリティグループ / WAF）
- パッチ適用方針
- 依存パッケージの脆弱性スキャン（Dependabot / Snyk 等）

## 7. 監査・インシデント対応

- 監査ログの取得対象
- 不正検知時のフロー
- インシデント発生時の通報・公表方針
