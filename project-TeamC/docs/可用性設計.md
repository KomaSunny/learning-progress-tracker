# 可用性設計

## 1. 可用性目標

| 指標     | 目標値              | 補足                          |
| -------- | ------------------- | ----------------------------- |
| SLO      | 例：月間 99.9%      | 月あたり停止許容 ≒ 43 分      |
| RTO      | 例：1 時間以内      | 障害発生から復旧までの目標    |
| RPO      | 例：15 分以内       | データロスト許容範囲          |

## 2. 冗長化構成

- アプリケーションサーバの多重化（複数 AZ）
- データベースのレプリカ構成
- ロードバランサ・DNS 冗長化

## 3. 障害シナリオと対応

| シナリオ             | 影響範囲   | 検知方法 | 対応 |
| -------------------- | ---------- | -------- | ---- |
| AZ 障害              | 一部 API   |          |      |
| DB プライマリ障害    | 書き込み   |          |      |
| 外部サービス障害     | 機能限定   |          |      |

## 4. ヘルスチェック

- 種類（liveness / readiness / 外形監視）
- 監視間隔・タイムアウト

## 5. 障害訓練

- フェイルオーバー試験の頻度
- カオスエンジニアリングの是非
