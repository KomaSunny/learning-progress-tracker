# 性能設計

## 1. 性能目標

| 項目                 | 目標値                  | 計測方法           |
| -------------------- | ----------------------- | ------------------ |
| 平均応答時間         | 例：300ms 以下          | APM / 負荷試験     |
| 95 パーセンタイル    | 例：1 秒以下            | APM / 負荷試験     |
| 同時接続ユーザー数   | 例：1,000 ユーザー      | 負荷試験           |
| スループット         | 例：100 req/sec         | 負荷試験           |
