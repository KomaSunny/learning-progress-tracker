# 運用設計

## 1. 運用体制

- 担当者・連絡網
- オンコールローテーション
- エスカレーションフロー

## 2. リリース運用

- リリースフロー（Git Flow / GitHub Flow など）
- リリース判定基準
- ロールバック手順

## 3. デプロイ

- 環境構成（開発 / ステージング / 本番）
- デプロイ手順 / CI・CD パイプライン
- データベースマイグレーション運用

## 4. 監視

- 監視対象（アプリ・インフラ・外形監視）
- 通知先（Slack / メール / PagerDuty）
- ダッシュボード

## 5. インシデント対応

- 発生時のフロー
- 一次対応 / 復旧 / 事後分析（ポストモーテム）
- SLA / SLO の取り扱い

## 6. バックアップ・リストア

- 取得対象・頻度・保管期間
- リストア手順とテスト計画

## 7. 定常運用タスク

- 日次 / 週次 / 月次タスク
- 棚卸し（不要リソース・権限の整理）
